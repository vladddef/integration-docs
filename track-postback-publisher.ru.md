# `GET https://t.trklinkx.com/click`

Server-to-server эндпоинт для отправки лида без формы на лендинге. Проверяет лид, проверяет его на дубликаты и регистрирует, после чего отвечает JSON.

- **URL:** `https://t.trklinkx.com/click`
- **Метод:** `GET`, параметры в query string
- **Авторизация:** query-параметр `sub30` (ваш API-ключ)
- **Всегда HTTP `200`.** Успех и ошибка различаются по полю `status` в теле ответа. Не полагайтесь на HTTP-код.
- **Content-Type:** `application/json`
- **Редиректы:** `https://t.trklinkx.com/click` перенаправляет запрос на наш эндпоинт, который возвращает JSON-ответ. Вы **обязаны следовать редиректам** (например, `curl -L`); иначе вы не получите ответ, а лид не будет зарегистрирован.

## Запрос

```
GET https://t.trklinkx.com/click?pid=11&offer_id=12716&sub1=6ade9d6a325c9f0001b40fdc&sub9=Ion%20Popescu&sub12=%2B40751382418&sub30=KEY&ip=203.0.113.7
```

Ваш HTTP-клиент должен следовать редиректу на наш эндпоинт. Без этого вы получите только ответ-редирект, а не JSON-результат.

### Обязательные параметры

Параметр, который отсутствует, пустой или передан несколько раз (`?pid=1&pid=2`), считается отсутствующим.

| Параметр | Описание |
|---|---|
| `sub30` | Активный API-ключ, выданный вам. |
| `pid` | ID паблишера / источника трафика. |
| `offer_id` | ID оффера. Также входит в ключ дубликата. |
| `sub9` | Имя клиента. Минимум 2 символа и минимум одна буква (латиница или кириллица). |
| `sub12` | Телефон клиента. Любой формат, но после удаления нецифровых символов должно остаться 7–15 цифр. |
| `sub1` | ID клика визита. |

### Необязательные параметры

| Параметр | Описание |
|---|---|
| `ip` | IP клиента. Если не передан, используется IP из заголовков запроса (`X-Real-IP`, затем последняя запись `X-Forwarded-For`). |

Любой другой параметр принимается и записывается в лог.

## Ответ

```json
{ "status": "ok" | "error", "data": { ... } }
```

## Примечания к поведению

- **Порядок проверок:** чёрный список IP → `sub30` → обязательные параметры → формат телефона и имени → проверка дубликата → регистрация.
- **Дубликаты:** ключ — это оффер плюс телефон без всех нецифровых символов, поэтому `+40 751 382 418` и `40751382418` совпадают. В течение 14 дней после успешной отправки тот же оффер + телефон возвращается как `duplicate`.
- **Логирование:** каждый вызов логируется, при этом API-ключ заменяется на `[redacted]`. Имя и телефон клиента в логе остаются.
- **Повторы:** временными могут быть только `connection_timeout` и `db`. Для них подождите и повторите запрос. Повтор после настоящего успеха вернёт `duplicate`.
